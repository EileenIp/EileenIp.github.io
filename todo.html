How to work together

Codex and Claude can read and update data/tasks.json in the project folder. Assigning a task does not start an assistant: ask the chosen assistant to pick it up.

Edits here are browser drafts. Use Connect shared file to select the project’s tasks.json, then Save shared file to share your changes. Reload the shared file before editing to see assistant updates. Other browsers can download JSON and replace data/tasks.json manually.

This page has no sign-in. Tasks committed to a public repository or published with the site are public.
