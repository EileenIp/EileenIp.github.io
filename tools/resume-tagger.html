Resume tagger

Every role and industry tag below was drafted, not supplied by you — correct anything that reads wrong. The tags decide which projects a recruiter's PDF shows, so a project tagged for a role it doesn't really support will end up in front of someone hiring for it. Your edits save as you go and survive a refresh. When you're done, hit Export and replace data/resume.json with the file it downloads.

Re-running scripts/build_resume_json.py regenerates the draft tags from the CV and would overwrite this, so export first if you've made changes.
